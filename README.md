# Inside Wedding

Видео для сайта Inside Wedding и готовые варианты вставки в Tilda.

## Видео

- `Inside-Wedding-1080p.mp4` — 1920×1004, H.264, 58,6 с, без звука.
- CDN-адрес: `https://cdn.jsdelivr.net/gh/OskarSerebrov/Inside-Wedding@v1.0-video/Inside-Wedding-1080p.mp4`

## Вставка в Tilda

1. Откройте нужную страницу.
2. Добавьте **Библиотека блоков → Другое → T123 «HTML-код»**.
3. Скопируйте в T123 весь код одного из файлов:
   - [`tilda/video-autoplay.html`](tilda/video-autoplay.html) — автозапуск, без звука, по кругу;
   - [`tilda/video-player.html`](tilda/video-player.html) — обычный плеер с кнопками управления.
4. Опубликуйте страницу. В редакторе и предпросмотре Tilda сторонний HTML-код может не запускаться.

Оба варианта адаптивные: видео занимает всю ширину блока и сохраняет исходные пропорции.
