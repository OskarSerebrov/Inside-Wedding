## Как вставить в Tilda

1. Откройте нужную страницу.
2. Добавьте **Библиотека блоков → Другое → T123 «HTML-код»**.
3. Скопируйте в T123 весь код нужного HTML-файла.
4. Опубликуйте страницу. Код может не запускаться в редакторе и предпросмотре Tilda.

Видео адаптивные, имеют обложки и не загружаются целиком до нажатия Play. На обложке показывается своя квадратная чёрная кнопка с белым треугольником.
